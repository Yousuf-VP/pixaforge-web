PIXAFORGE — VISUAL UPGRADE PACK

Included:
- style.css: replacement stylesheet for the latest index(1).html found in your project files.
- script.js: navigation, scroll reveals, subtle desktop card tilt, cursor glow, and carousel keyboard support.

INSTALL:
1. Back up your current style.css and script.js.
2. Replace them with the files in this ZIP.
3. Keep your existing index.html unchanged.
4. Keep your existing assets in the same locations:
   favicon.png, word.png, game.png
5. Open index.html and test desktop + mobile widths.

MOBILE CAROUSEL:
The games row becomes a touch/swipe carousel on screens 700px and below, with momentum scrolling and snap-to-card behaviour. Desktop keeps the three-card grid.

NOTE:
This pack does not include image assets because the indexed project files available for inspection contained the HTML/CSS/JS source only. It does not alter your HTML or rename your assets.
